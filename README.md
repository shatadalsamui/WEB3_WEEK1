# Week 1: Web3 Fundamentals - Byte Manipulation and Hashing

This directory contains JavaScript files demonstrating fundamental Web3 concepts related to byte manipulation, encoding, and hashing.

## File Descriptions

1. **asciitoByte array.js** - Converts ASCII strings to byte arrays
2. **base64encode.js** - Demonstrates Base64 encoding operations
3. **bits.js** - Basic bit manipulation operations
4. **bytesTOascii.js** - Converts byte arrays back to ASCII strings
5. **hashing1.js** - Basic hashing operations (likely SHA-256)
6. **hashing2.js** - More advanced hashing operations
7. **unit8array.js** - Uint8Array operations (common in Web3 for binary data)
8. **web3.js** - Basic Web3.js setup or operations

## Usage

Each file contains self-contained JavaScript code that can be run with Node.js:
```bash
node filename.js
```

## Concepts Covered
- Byte array manipulation
- ASCII/Base64 encoding
- Cryptographic hashing
- Uint8Array operations
- Basic Web3.js functionality
